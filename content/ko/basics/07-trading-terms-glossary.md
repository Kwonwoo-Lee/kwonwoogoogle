## 왜 미리 용어부터 정리할까

매매기법 코스는 각 전략을 설명할 때마다 그 안에서 필요한 용어를 그때그때 설명하지만, 여러 강의에 걸쳐 반복적으로 나오는 용어들을 한곳에 모아두면 훨씬 헷갈리지 않습니다. 이 강의는 새로운 개념을 가르치는 게 아니라, **앞으로 나올 용어들의 지도**를 미리 그려두는 용도입니다. 각 항목 옆에 자세히 다루는 강의를 표시해뒀으니, 매매기법 코스를 보다가 헷갈리면 다시 돌아와 확인하셔도 좋습니다.

## 추세를 따라가는 지표

- **이동평균선(MA, Moving Average)**: 최근 N일 종가의 평균을 이은 선. 짧으면 최근 가격에 민감하고, 길면 큰 흐름을 완만하게 보여줍니다. → 매매기법 1강
- **골든크로스 / 데드크로스**: 단기 이동평균선이 장기 이동평균선을 위/아래로 뚫고 지나가는 지점. 각각 매수·매도 신호로 해석됩니다. → 매매기법 1강
- **SMA / EMA**: 이동평균선을 계산하는 두 가지 방식. SMA는 모든 날짜에 같은 비중을, EMA는 최근 날짜에 더 큰 비중을 둡니다. → 매매기법 1강

## 힘의 세기를 재는 지표

- **RSI (상대강도지수)**: 최근 상승폭과 하락폭을 비교해 0~100 사이 값으로 나타낸 지표. 70 이상은 과매수, 30 이하는 과매도로 흔히 해석되지만, 전략에 따라 반대로 해석되기도 합니다. → 매매기법 2강
- **모멘텀**: 가격이 최근 얼마나 강하게, 얼마나 꾸준히 한 방향으로 움직였는지를 나타내는 개념. → 매매기법 2강
- **상대강도(시장 대비)**: 개별 종목의 수익률을 업종·시장 지수와 비교한 것. → 매매기법 2강

## 가격의 널뛰기 폭을 재는 지표

- **볼린저밴드**: 이동평균선 위아래로 표준편차만큼 띄운 밴드. 가격이 밴드에 닿으면 과열·과매도로 해석합니다. → 매매기법 3강
- **Z-스코어**: 지금 가격이 평균에서 표준편차 몇 배만큼 떨어져 있는지를 정확한 숫자로 나타낸 값. → 매매기법 3강

## 가격대와 관련된 용어

- **지지선 / 저항선**: 하락(상승)이 반복적으로 멈췄던 가격대. 저항선을 강하게 뚫으면 이후 지지선으로 역할이 바뀌기도 합니다. → 매매기법 4강
- **브레이크아웃**: 오래 갇혀있던 박스권을 뚫고 나가는 움직임. → 매매기법 4강
- **거래량 프로파일**: 가격이 아니라 각 가격대에서 실제로 거래된 물량을 보여주는 지표. → 매매기법 4강

## ICT·스마트머니 관련 용어

- **유동성(Liquidity)**: 직전 고점·저점 부근에 쌓여있는 손절·대기 주문의 뭉치. → 매매기법 5강
- **유동성 스윕**: 그 고점·저점을 살짝 뚫었다가 빠르게 되돌아오는 움직임. → 매매기법 5강
- **FVG (페어밸류갭)**: 가격이 빠르게 움직이며 3개 캔들 사이에 남긴 거래 공백. → 매매기법 5강
- **HTF / LTF**: 상위 시간대(Higher Time Frame)와 하위 시간대(Lower Time Frame). 방향은 HTF에서, 정밀한 진입 타이밍은 LTF에서 잡습니다. → 매매기법 5강
- **PO3 (Power of Three)**: 축적(다지기) → 조작(가짜 이탈) → 분산(진짜 움직임)으로 이어지는 시장의 3단계 리듬. → 매매기법 7강
- **DOL (Draw On Liquidity)**: 가격이 끌려갈 것으로 예상되는 유동성 목표 지점. → 매매기법 5·7강
- **프리미엄 / 디스카운트**: 최근 스윙 구간의 절반(균형점)보다 가격이 위(프리미엄)인지 아래(디스카운트)인지. → 매매기법 7강
- **킬존**: 기관 자금이 몰린다고 여겨지는 특정 시간대. 뉴욕 정규장 시작 직후가 대표적. → 매매기법 7강

## 매매 관리와 관련된 용어

- **손절가 / 목표가**: 진입 후 "틀렸다"고 인정하고 나갈 가격(손절가)과 원하는 이익을 실현할 가격(목표가). → 주식 기초 3강, 매매기법 6강
- **손익비 (R:R, Risk-Reward Ratio)**: 감수하는 리스크 대비 기대 이익의 비율. "1:3"이면 1을 걸어 3을 노린다는 뜻. → 매매기법 6강
- **R멀티플**: 실제 손익을 최초 리스크 대비 몇 배인지로 환산한 값. 서로 다른 거래를 같은 잣대로 비교할 때 씁니다. → 매매기법 6강
- **켈리 공식**: 승률과 손익비를 바탕으로 수학적인 "최적" 포지션 크기를 계산하는 공식. → 주식 기초 6강

## 이 표를 어떻게 활용하면 좋을까

한 번에 다 외우려 하지 마세요. 매매기법 코스를 하나씩 들으면서 낯선 용어가 나올 때마다 이 강의로 돌아와 확인하는 용도로 쓰는 게 훨씬 효율적입니다. 몇 번 반복해서 마주치다 보면 자연스럽게 익숙해집니다.

## 정리

- 이 강의는 새 개념이 아니라 **앞으로 나올 용어들의 지도**입니다.
- 추세(이동평균선) → 힘의 세기(RSI) → 변동폭(볼린저밴드) → 가격대(지지·저항) → ICT 용어(유동성·FVG) → 매매 관리(손익비) 순으로 정리했습니다.
- 매매기법 코스를 보다가 막히면 언제든 이 강의로 돌아와 확인하세요.
